# Toll Plaza Revenue Analysis using Power BI

## Project Overview

This project analyzes toll plaza revenue and vehicle traffic across India using Microsoft Power BI.

The dashboard provides insights into revenue collection, vehicle traffic, payment methods, revenue loss, and toll plaza performance.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel / CSV

## Dashboard Pages

### 1. Overview
- Total Revenue
- Expected Revenue
- Collected Revenue
- Revenue by State
- Revenue by Payment Method
- Revenue by Month
- Revenue by Toll Plaza

### 2. Revenue Analysis
- Revenue by Vehicle Type
- Revenue by Shift
- Collected vs Expected Revenue
- Revenue by Highway
- Holiday vs Non-Holiday Revenue

### 3. Vehicle Analysis
- Vehicle Count by State
- Vehicle Count by Time Slot
- Vehicle Count by Month
- Toll Exemption Analysis

### 4. Revenue Loss Analysis
- Revenue Loss by State
- Revenue Loss by Toll Plaza
- Revenue Loss by Month
- Revenue by Vehicle Type
